# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Added setting and editing of all `TDF_SPEC.md` Section 4.1 task capabilities across `TaskBoard`, `TaskNotifier`, `TaskItem`, `tdf_metadata.dart`, and `TaskEditorDialog` (`lib/ui/widgets/task_editor_dialog.dart`), including `Suspended` (`suspended` toggle + optional `<YYYY-MM-DD> [<HH:MM[:SS]>]` timestamp that disables evaluation of all other conditions and classifies the task under `Blocked` per `TDF_SPEC.md` Sections 4.1.2, 5.3, 5.4, and 6.6), prerequisite tasks (`blocked` multi-select with self-dependency and circular-dependency prevention via `TaskBoard.wouldCreateDependencyCycle`), and activation conditions (`condition any`, `day any` / `day <mon..sun>`, `time any` / `time <HH:MM> <HH:MM>`, and `location any` / `location <lat> <lon> <radius>`).
- Added completed task restoration per `TDF_SPEC.md` Section 6.5 (`TaskBoard.restoreTask`, `TaskBoard.updateTask`, `TaskNotifier.restoreTask`, `_TierTaskPill`, and `TaskEditorDialog`): tapping the leading checkmark circle (`complete_task_button_<id>`) on a completed task restores it to `Planned` (removing `finished` and `priority` and setting `queued` to `now`), while editing a completed task via `TaskEditorDialog` defaults to `Planned` and allows restoring to `Planned`, `Priority` (`Focus`), or `Someday`, without evaluating conditions on tasks while in `Completed` (`TDF_SPEC.md` Section 5.2).
- Added a Google Keep style `Labels` section in the left navigation drawer (`_LandingDrawer` in `lib/ui/home_screen.dart`) with a top-right `Edit` button (`drawer_edit_labels_button`), selectable label filter pills (`drawer_label_tile_<id>`) preserving open task count badges (`drawer_label_badge_<id>` via `TaskBoard.openTaskCountForLabel`), and a `+ Create new label` entry (`drawer_create_label_tile`), alongside a dedicated `EditLabelsScreen` (`lib/ui/edit_labels_screen.dart`) for creating, renaming (`TaskBoard.renameLabel` / `TaskNotifier.renameLabel`), and deleting (`TaskNotifier.deleteLabel`) labels with open task counts.
- Added a downward arrow downgrade button (`downgrade_task_button_<id>`) on `Focus`, `Ready`, and `Planned` task pill cards (`_TierTaskPill`) immediately to the left of the 3px vertical gap on the right side, and implemented `TDF_SPEC.md` Section 6.3 downgrade rules (`TaskBoard.downgradeTask` and `TaskNotifier.downgradeTask`) for downgrading from `Focus` to `Ready` (`< 8` active tasks vs. `>= 8` active tasks with slot `8` priority alignment, `+00:00:01` timestamp offset, and `Planned` collision shifting), from `Ready` to `Planned`, and from `Planned` to `Someday`.
- Added `TDF_SPEC.md` Version 0.2.0 (`tdf 0.2.0` header) support in `TdfService`, `TaskBoard`, and `tdf_metadata.dart`, including unified `label <id> { ... }` root blocks (`TdfLabel`), `labels <id...>` task directives, `condition { ... }` sub-blocks, Haversine GPS `location <lat> <lon> <radius>` rules (`LocationTaskCondition`), group-level condition inheritance and overrides (`<type> any` via `GroupResetTaskCondition` and `condition any` via `GlobalResetTaskCondition`), optional seconds precision (`<HH:MM[:SS]>`) on timestamps, `MAX_NOTE_LENGTH` (`2000`), and cycle detection (`CircularDependency`).
- Added a right-side edit button on task pill cards (`_TierTaskPill`) across the tier panels and a shared `TaskEditorDialog` (`lib/ui/widgets/task_editor_dialog.dart`) used for both extended task creation (`QuickAddBar` `Advanced` button) and task editing, enforcing non-empty and non-duplicate task names while supporting notes, `Priority` / `Someday` scheduling, labels, and subtasks (`auto-finish`).
- Added `TierPageIndicator` (`lib/ui/widgets/tier_page_indicator.dart`) and horizontal 6-tier `PageView` sliding (`Focus`, `Ready`, `Planned`, `Blocked`, `Someday`, `Completed`) on `HomeScreen`, rendering above `QuickAddBar` when the add button is pressed, showing dots for inactive tiers and an icon for the active tier over a transparent background, displaying the hovered tier icon in an intermediate color and a borderless tier name pill on desktop mouse-over without wave animation, supporting desktop Left/Right arrow key navigation, and applying a wave effect on hold and drag that enlarges the two adjacent neighbor dots (`1.5x` in the intermediate color) and jumps directly to the selected tier pane upon release.
- Added single-pass $O(N)$ TierTask Data Format (`.tdf`) lexical scanner, structural parser, and canonical `LF` serializer (`TdfService`) implementing [`TDF_SPEC.md`](TDF_SPEC.md) with all Section 7 resource bounds and Section 8 `TdfErrorKind` diagnostics.
- Added `ConditionGroup` (`day`, `time`, `location`), `TaskCondition`, and `TdfLabel` models (`lib/models/tdf_metadata.dart`) and dynamic 6-tier evaluation (`TaskBoard.evaluate` and `TaskBoard.evaluateForContext`) with `subtasks auto-finish` checklist completion.
- Added `Open Task Count` (`Off` by default, `On`) setting in Settings.
- Added storage mode selection (`Local`, `WebDAV`, `Both`), configurable local `.tdf` file name (`localFilePath`, defaulting to `tiertask.tdf`), and local filesystem persistence via `LocalFileRepository`.
- Added color theme selection (`System`, `Light`, `Dark`) in Settings with `System` as the default mode.
- Added English (`en`, default) and German (`de`) localization via external ARB files (`lib/l10n/app_en.arb`, `lib/l10n/app_de.arb`) with `System`, `English`, and `Deutsch` language selection in Settings.
- Added Linux, Android, and Windows platform support for the 6-tier task board.

### Changed
- Changed `_LandingTopBar` on `HomeScreen` (`lib/ui/home_screen.dart`) to display the selected label's name centered in the top bar when a label filter is active (omitting a title when no label is selected), and to smoothly animate the label name to the left next to the menu button while expanding and fading in the search input between the label name and the search icon when search is opened.
- Changed `QuickAddBar` (`lib/ui/widgets/quick_add_bar.dart`) to automatically stack the task title input field above the action buttons (`Priority`, `Someday`, `Labels`, `Advanced`, `Cancel`) when the viewport width matches or drops below the Pixel 9 Pro width/aspect-ratio threshold (`<= 488` dp or `<= height * 1280 / 2856`), while keeping the single-row side-by-side layout on wider viewports.
- Changed `_TierPaneHeader` on `HomeScreen` (`lib/ui/home_screen.dart`) to display the selected label's name instead of the default greeting (`What's up!` / `Was steht an!`) whenever a label filter is active.
- Changed `TdfService.parse`, domain models (`TdfLabel`, `TaskItem.labelIds`, `TaskBoard.labels`), Riverpod providers (`TaskNotifier`), UI widgets (`QuickAddBar`, `TaskEditorDialog`), and localization bundles (`app_en.arb`, `app_de.arb`) to unify `category` and `location` into `label` and automatically migrate legacy `category` / `location` (`gps`) blocks and `categories` / `locations` directives to `tdf 0.2.0` `label` / `labels` on parse and save.
- Changed task pill cards (`_TierTaskPill`) so only the leading completion circle and the right-side edit button are clickable (rather than the entire task card), and added a full-height 3px vertical gap matching the screen background before the edit button.
- Changed all 6 tier panels (`Focus`, `Ready`, `Planned`, `Blocked`, `Someday`, `Completed`) on `HomeScreen` to share the same layout and visual styling as the `Focus` landing screen, displaying the top greeting (`What's up!` / `Was steht an!`), uppercase tier section heading, minimalist task pill cards (`_TierTaskPill`), and empty-state card (`_EmptyTierCard`), with left drawer tier items navigating directly to the corresponding `PageView` panel.
- Changed persistence across `LocalFileRepository`, `WebDavRepository`, `SecureSettingsRepository`, `WebDavConfig`, and `TaskNotifier` to store and synchronize `.tdf` documents (`tiertask.tdf` / `t2.tdf`) with primary local persistence.
- Changed `QuickAddBar` into a single-row inline bottom bar that replaces the circular `+` add button when clicked, featuring a borderless task title input on the left followed by `Priority`, `Someday`, an upward-expanding `Labels` multi-select button, an `Advanced` button, and a `Cancel` button.
- Changed `HomeScreen` into a streamlined landing page displaying the top greeting (`What's up!` / `Was steht an!`), minimalist `Focus` task cards, a top-right search filter with a conditional WebDAV sync icon (`WebDAV` or `Both` storage mode), and a top-left navigation drawer housing secondary tiers and actions without `Categories` or `Locations` sections on the landing page or side panel.
- Changed status banners in Settings (save confirmation, WebDAV connection success, and synchronization error messages) to fade out and dismiss automatically after a few seconds.
- Changed the localized application title (`appTitle`) from `TierTask (T2)` to `TierTask`.
- Changed UI tier headings, tab labels, and quick-add chips to display localized tier names (`Focus`, `Ready`, `Planned`, `Blocked`, `Someday`, `Completed`).

### Removed
- Removed the `What's up!` / `Was steht an!` greeting (`landingGreeting`) and the active label title from above the tier section heading in `_TierPaneHeader` on `HomeScreen`.
- Removed the tier navigation entries (`Focus`, `Ready`, `Planned`, `Blocked`, `Someday`, `Completed`) from the side panel navigation drawer (`_LandingDrawer`).
- Removed legacy `TaskTile` (`lib/ui/widgets/task_tile.dart`), `RestoreTaskSheet` (`lib/ui/widgets/restore_task_sheet.dart`), the `Move to...` / `Edit text` / `Delete` entry overflow menu and quick-action buttons, and associated `moveTask`, `restoreTask`, `editTaskTitle`, and `deleteTask` methods.
- Removed Markdown (`.md`) parsing, serialization, and `MarkdownService` in favor of the TierTask Data Format (`.tdf`).

### Fixed
- Fixed Linux and Windows native window, header bar, and taskbar titles to display `TierTask` instead of `tiertask`.
- Fixed Settings to disable the `Test Connection / Sync Now` button in `Local` storage mode and clear stale status banners so WebDAV connection success is never displayed when WebDAV is unconfigured or invalid.
- Fixed ISO-8601 date and 24-hour timestamp parsing in `TaskItem` and `TdfService` to reject out-of-range calendar rollover dates.
